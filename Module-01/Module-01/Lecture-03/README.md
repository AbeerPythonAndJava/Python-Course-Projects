# 🐍 Lecture 03 — String Methods & User Input

## 🎯 Learning Objectives

By the end of this lecture, students will be able to:

- Receive user input using `input()`.
- Convert text to uppercase and lowercase.
- Remove leading and trailing spaces.
- Calculate the length of a string.
- Split a string into words.
- Replace text within a string.
- Combine multiple string operations in one program.

## 📝 Lecture Exercises

| Exercise | Title | Description |
|---|---|---|
| 01 | User Information | Receive and display user information. |
| 02 | Upper & Lower | Convert text to uppercase and lowercase. |
| 03 | Strip & Len | Remove extra spaces and calculate string length. |
| 04 | Split | Split a full name into separate words. |
| 05 | Replace | Replace words in a sentence. |
| 06 | Student Name Formatter | Combine multiple string operations in one program. |

## 🧠 Programming Concepts

- `input()`
- `upper()`
- `lower()`
- `strip()`
- `len()`
- `split()`
- `replace()`
- Variables and `print()`

## 💡 Think Before You Code

Before writing your program:

1. Identify the input required from the user.
2. Decide which string operations are needed.
3. Store the input in meaningful variables.
4. Apply the appropriate string methods.
5. Display the results and verify the output.
