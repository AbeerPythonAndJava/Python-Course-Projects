## 🐍 Lecture 02 — Python Variables

## 🎯 Learning Objectives

By the end of this lecture, students will be able to:

- Understand what variables are in Python.
- Declare variables and assign values.
- Display variable values using "print()".
- Follow Python variable naming rules.
- Identify valid and invalid variable names.
- Update the value of an existing variable.

## 📝 Lecture Exercises

Exercise| Title| Description
01| Student Information| Store and display student information using variables.
02| Product Information| Define variables for product details and print their values.
03| Variable Naming Rules| Identify valid and invalid Python variable names.
04| Updating Variables| Change the value of a variable and display the result.

## 🧠 Programming Concepts

- Variables
- Assignment operator ("=")
- Variable naming conventions
- Python keywords
- Updating variable values
- "print()" function

💡 Think Before You Code

Before writing your Python program:

1. Identify the information you need to store.
2. Choose meaningful variable names.
3. Assign values to your variables.
4. Decide what information to display.
5. Write your code and check the output.

- Basic use of the "print()" function
