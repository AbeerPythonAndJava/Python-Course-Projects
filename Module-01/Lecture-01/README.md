## 🎯 Learning Objectives

By the end of this lecture, students will be able to:

- Understand the purpose of the "print()" function.
- Display text using Python.
- Print multiple lines of output.
- Create simple text patterns.
- Format basic console output.

💡 Think Before You Code

Before writing your Python code:

1. Understand the required output.
2. Identify the text you need to display.
3. Decide how many "print()" statements you need.
4. Write your Python code.
5. Run the program and check the output.
